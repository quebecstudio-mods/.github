# Support

## A question or a bug

Open an issue in the repository of the package concerned, in English. Say which
package and version you run, on which platform and PHP version, and what you
expected instead of what happened.

Each package documents what it does and does not do; its README is the
reference, and issues are read against it.

## Security

Write to info@quebecstudio.com rather than opening an issue. See
[SECURITY.md](SECURITY.md).
