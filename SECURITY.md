# Security policy

## Reporting a vulnerability

Write to **info@quebecstudio.com**. Do not open a public issue: a flaw is worth
keeping quiet until it is fixed.

Include the package and version, what an attacker can do with the flaw, and the
steps to reproduce it. A proof of concept helps, but a clear description is
enough.

Once a fix ships, the release notes say what was fixed and credit you by the
name you choose, unless you prefer none.

## Supported versions

The latest release of each package. Older majors receive security fixes only
while the platform they target is itself supported.
