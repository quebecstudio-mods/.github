# Québec Studio Mods

Plugins and packages for Craft CMS, Statamic and Laravel, made by
[Québec Studio](https://quebecstudio.com) in Rouyn-Noranda, Quebec.

## Cookie Consent Kit

An opt-in cookie consent banner: no cookie, script or third-party embed loads
before the visitor agrees. Written for Quebec's Law 25 and usable under the
GDPR.

| Package | For |
|---|---|
| `quebecstudio-mods/craftcms-consent-kit` | Craft CMS 5 (PHP 8.2+) and 6 (PHP 8.5+) |
| `quebecstudio-mods/statamic-consent-kit` | Statamic 6, PHP 8.2+ |
| `quebecstudio-mods/laravel-consent-kit` | Laravel 11 to 13, PHP 8.2+ |
| `quebecstudio-mods/consent-kit-core` | the framework-free core the integrations are built on, PHP 8.2+ |
| `quebecstudio-mods/consent-kit-register` | the consent register shared by the CMS integrations, PHP 8.2+ |
