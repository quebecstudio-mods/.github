# Contributing

## Issues are the way in

Bug reports and feature requests are welcome in the repository of the package
concerned, in English.

## Pull requests

These repositories are published snapshots: each release is exported from a
private working repository, so a pull request cannot be merged as it stands.

Open an issue with the change you have in mind — a patch or a diff in the issue
is perfectly readable, and gets applied upstream with credit in the release
notes.

## What guides the code

Each package documents its own contract: the markup, the CSS classes, the
public API and the settings it promises to keep. They change only on a major
version.
